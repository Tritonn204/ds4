# Qwen3.6 Study And Export Tooling

This directory is the tracked home for the Qwen3.6 narrow-runtime study tools
that previously lived under ignored `misc/`.

The files here are intentionally broad. They include one-off probes, reusable
oracles, fixture exporters, runtime comparison scripts, prompt fixtures, and
study notes. Do not cull them casually; many encode the debugging trail needed
to reproduce the current Qwen runtime contract.

## Current Canonical Artifact Lane

The active Q4+Q2 artifact lane is:

- preserve original Q2-safe routed expert tensors
- use Q4 for the remaining routed expert surfaces
- keep resident/root tensors copied from the validated Q4XL template

Relevant commands:

```bash
python3 gguf-tools/qwen36/qwen36_q4_original_q2_policy.py \
  --from-study-default \
  --out /tmp/qwen36_q4_original_q2_policy.json
```


## Validation After Moving Or Editing

Run these cheap checks after touching this directory:

```bash
python3 -m py_compile gguf-tools/qwen36/*.py
bash -n gguf-tools/qwen36/*.sh
```

Then remove generated bytecode before committing:

```bash
rm -rf gguf-tools/qwen36/__pycache__
```

For Q4+Q2 export-path sanity:

```bash
python3 gguf-tools/qwen36/qwen36_q4_original_q2_policy.py \
  --from-study-default \
  --out /tmp/qwen36_q4_original_q2_policy.json
```

Expected summary:

```text
routed_tensors=120 q2_preserved=102 q4_assigned=18
```
